# 教学管理平台教师端使用指南

## 📗 教师版使用指南

### 一、登录与首页

1. 输入用户名与密码登录。
  - 登录只接受唯一用户名；真实姓名仅用于展示和检索，不能作为登录凭证。
2. 进入教师总览页面，显示：
   - **任务组合指标**：进行中任务、作业最多参与人数、待完成人次、首次正确率
   - **任务概览**：每个任务的完成率、正确率、个人状态对应人数和截止时间，可直接进入作业详情
   - **学生名册**：姓名、账号、班级、登录状态

### 二、题目任务管理

#### 发布任务流程
1. 进入「任务管理」页面，先在顶部切换到目标班级
2. 填写任务名称（最多 20 个字符），可设置开始时间与截止时间
3. 从右侧题库中选择题目，点击「加入」
4. 已选题目支持调整顺序（↑↓）和移除（×）
5. 可点击「保存为新草稿」，或直接「发布任务」

同一班级内可以同时存在多个进行中的作业。任务生命周期为：草稿 → 已发布 → 已截止 → 已归档。

- 草稿：仅教师可见，可继续编辑
- 已发布：在开始时间后、截止时间前允许学生作答；也可设置为未来开始
- 已截止：学生不能再提交，但历史作答与题目快照保留
- 已归档：从任务列表移入历史，保留全部学习数据

题目在发布时生成快照，之后修改题库不会改变已发布任务。

教师端任务只包含题目，不再配置实验、过渡视频或选项讲解视频。学生端另有独立的 3D 实验入口，由学生自由操作，不参与任务完成判断。

#### 作业详情

在任务列表中点击「作业详情」，可以查看单次作业的提交与完成情况：

- 应参与、已参与、已完成及尚未答完人数
- 首次正确率
- 学生完成情况表：开放期间可按未开始/进行中/已完成筛选；截止后按未交/未完成/已完成筛选
- 每题正确率、作答人数和未作答人数
- 导出 CSV 学生明细
- 跳转到该任务的原始答题记录

作业详情只统计首次作答，补练单独保留，不计入作业完成率。

### 三、班级管理

- 进入「班级管理」页面
- 创建班级后自动成为负责教师
- 可将学生加入班级，一个学生只能属于一个主班
- 负责教师可添加或移出协作教师，班级至少保留一位负责教师
- 顶部班级切换器决定总览、任务管理和学生名册的查看范围

### 四、学生学情分析

#### 查看学生列表
- 进入「学生学情」页面
- 显示所有学生的：
  - 总答题数、错题数、错误率
  - 可按班级筛选
  - 可按姓名/用户名搜索

#### 查看学生详情
- 点击学生姓名，查看：
  - **学习报告**：该学生个人 AI 生成的学习报告
  - **全部记录**：学生所有答题情况
  - **错题记录**：仅显示错题
  - **记录详情**：题目内容、选项、解析

#### 教师调阅报告
- 教师可随时调取查阅学生已生成的学习报告
- 了解每位学生的个性化学习情况

### 五、学生名册

- 进入「学生名册」页面
- 集中维护学生：姓名、账号、班级、启停状态
- 支持按姓名、账号、班级搜索，或按启用状态筛选
- 可编辑学生信息、启用或停用学生账号
- 教师账号不在此页面维护

### 六、题库管理

- 进入「题库管理」页面
- 支持题目的增、删、改、查操作
- 可配置题目的题干、选项、正确答案、解析和难度；公式使用 LaTeX 格式
- 题目任务发布后保存题目快照，之后修改题库不会改变历史作答

任务名单在发布时保存，新加入学生仅加入尚未截止任务；已分配账号停用后仍保留历史。迁移前名单会明确标记无法还原原始分配范围。题库与选题支持服务端分页和搜索，跨页选题不会丢失；编辑时读取完整题目及配图。
