# 智学物理教学平台使用指南

## 📗 教师版使用指南

### 一、登录与首页

1. 输入用户名与密码登录。
  - 登录只接受唯一用户名；真实姓名仅用于展示和检索，不能作为登录凭证。
2. 进入教师总览页面，显示：
   - **任务完成情况**：当前启用学生的已完成/未完成比例
   - **总答题正确率**：班级整体答题质量
   - **关键指标**：累计答题次数、学生人数、题库题目数
   - **当前教学任务**：已发布的任务信息
   - **学生名册**：姓名、账号、班级、登录状态
   - **快捷入口**：常用功能的快捷入口

### 二、题目任务管理

#### 发布任务流程
1. 进入「任务管理」页面
2. 填写任务名称（最多 20 个字符），可设置开始时间与截止时间
3. 从右侧题库中选择题目，点击「加入」
4. 已选题目支持调整顺序（↑↓）和移除（×）
5. 可点击「保存为新草稿」，或直接「发布任务」

单班内可以同时存在多个进行中的作业。任务生命周期为：草稿 → 已发布 → 已截止 → 已归档。

- 草稿：仅教师可见，可继续编辑
- 已发布：在开始时间后、截止时间前允许学生作答；也可设置为未来开始
- 已截止：学生不能再提交，但历史作答与题目快照保留
- 已归档：从任务列表移入历史，保留全部学习数据

题目在发布时生成快照，之后修改题库不会改变已发布任务。

教师端任务只包含题目，不再配置实验、过渡视频或选项讲解视频。学生端另有独立的 3D 实验入口，由学生自由操作，不参与任务完成判断。

#### 作业详情

在任务列表中点击「作业详情」，可以查看单次作业的提交与完成情况：

- 应交、已参与、已完成、未交、未完成人数
- 首次正确率
- 学生完成情况表：可按未交/未完成/已完成筛选
- 每题正确率、作答人数和未作答人数
- 导出 CSV 学生明细
- 跳转到该任务的原始答题记录

作业详情只统计首次作答，补练单独保留，不计入作业完成率。

### 三、学生学情分析

#### 查看学生列表
- 进入「学生学情」页面
- 显示所有学生的：
  - 总答题数、错题数、错误率
  - 可按班级筛选
  - 可按姓名/用户名搜索

#### 查看学生详情
- 点击学生姓名，查看：
  - **学习报告**：该学生个人 AI 生成的学习报告
  - **全部记录**：学生所有答题情况
  - **错题记录**：仅显示错题
  - **记录详情**：题目内容、选项、解析

#### 教师调阅报告
- 教师可随时调取查阅学生已生成的学习报告
- 了解每位学生的个性化学习情况

### 四、用户管理

- 进入「用户管理」页面
- 集中维护：姓名、账号、班级、身份、启停状态
- 支持搜索（姓名/账号/班级）
- 可禁用/启用学生账号，或者修改其他学生的部分个人信息

### 五、题库管理

- 进入「题库管理」页面
- 支持题目的增、删、改、查操作
- 可配置题目的题干、选项、正确答案、解析和难度；公式使用 LaTeX 格式
- 题目任务发布后保存题目快照，之后修改题库不会改变历史作答
