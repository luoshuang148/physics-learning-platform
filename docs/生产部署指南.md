# 智学物理单机生产部署指南（2C2G，无 Nginx）

## 1. 部署目标

- 单台云服务器部署
- 前后端合并为一个应用容器
- MySQL 独立容器
- 不引入 Nginx 反向代理
- 所有持久化数据落盘到 /data

## 2. 当前改造结果

本仓库已完成以下生产改造：

- Docker 多阶段构建改为“前端先构建，再打进后端 jar 的 static 目录”
- docker-compose 默认本地构建 app 镜像，不依赖外部镜像仓库
- 前端 API 调用基址统一，移除 localhost 硬编码
- Vue Router 生产构建 base 默认 /api/v1/，并支持构建时覆盖
- 后端新增 Vue history 路由回退（/auth、/student、/teacher、/preview）
- 生产配置支持 DB_HOST/DB_PORT/DB_NAME、VIDEO_STORAGE_PATH 等变量化
- 生产环境关闭 Swagger 文档，仅暴露 health/info

## 3. 环境变量（必做）

1. 在项目根目录复制模板：

```bash
cp .env.production.example .env
```

2. 修改 .env 的真实值：

- DB_PASSWORD
- APP_JWT_SECRET
- ALIYUN_AI_API_KEY
- ZHIPU_AI_API_KEY
- APP_CORS_ALLOWED_ORIGIN

说明：

- 前端变量 VITE_APP_BASE、VITE_API_BASE_URL 是构建时变量，不是运行时变量。
- 当前推荐同域部署，VITE_API_BASE_URL 保持空即可。

## 4. 启动部署

在项目根目录执行：

```bash
docker compose up -d --build
```

查看状态：

```bash
docker compose ps
docker compose logs -f app
```

## 5. 访问地址

- 前端入口：http://<你的域名或公网IP>/api/v1/
- 后端健康检查：http://<你的域名或公网IP>/api/v1/actuator/health

## 6. 更新发布

代码更新后执行：

```bash
docker compose up -d --build
```

## 7. 回滚（快速）

如果新版本异常：

1. 回到上一版代码（git checkout 到上一个稳定提交）
2. 重新执行：

```bash
docker compose up -d --build
```

## 8. 常见问题

### 8.1 页面能开但刷新 404

确认访问路径是 /api/v1/ 开头，例如：

- 正确：http://<ip>/api/v1/
- 错误：http://<ip>/

### 8.2 AI 接口报 401 或 500

检查 .env 中的：

- APP_JWT_SECRET
- ALIYUN_AI_API_KEY
- ZHIPU_AI_API_KEY

并执行：

```bash
docker compose restart app
```

### 8.3 MySQL 连接失败

检查：

- docker compose ps 中 mysql 是否 healthy
- .env 中 DB_USER/DB_PASSWORD 是否与初始化一致
- /data/mysql 权限是否可写
