# AI 应用演示脚本（约 4 分钟）

只在本地隔离演示环境使用合成账号、题目、作答和讲义。不要展示真实学生信息。默认不启用动态 Agent；演示页会显示实际运行模式。

| 时间 | 操作 | 要讲清楚的工程点 |
|---|---|---|
| 0:00–0:30 | 展示部署和模式状态页 | 知识服务可选；固定工作流默认启用；Agent 需配置后才可运行 |
| 0:30–1:25 | 上传演示讲义，查看切片/索引状态，再展示 RAG 错题答案来源 | 资料按班级隔离；召回来源进入答案；引用不是模型编造的标签，历史来源重新鉴权 |
| 1:25–2:35 | 学生选择作业，询问“根据本次作业安排三天复习” | 后端认证确定学生身份；工具只读本人作答/知识与题库候选；学生不能传 userId；运行步骤和依据可见 |
| 2:35–3:20 | 检查计划题目与来源，保存并激活 | 生成先预览；服务端重新校验作答版本和题目；旧版本计划会拒绝激活 |
| 3:20–3:50 | 进入补练并展示计划进度，打开运行详情 | 首次分数和补练分开；日志记录耗时和可用 token 用量，缺价格时费用保持未知 |
| 3:50–4:20 | 展示一条失败场景和评测状态 | 部分计划不冒充完整成功；当前自动测试通过，但实际模型质量和教师复核尚未完成 |

## 演示前检查

1. 按 [本地启动指南](../项目启动指南.md) 启动空库或专用演示库，运行 `./mvnw -B -Dgroups=unit test`、前端 `npm test && npm run build`。前端 mock E2E 需先启动 Vite，再用 `E2E_BASE_URL=http://127.0.0.1:4173/ npm run test:e2e -- knowledge-tutoring.spec.ts learning-assistant.spec.ts`。
2. 启动 Qdrant 并设置 `APP_KNOWLEDGE_ENABLED=true` 才演示 RAG。否则跳过资料辅导，不把关闭状态说成服务故障。
3. 使用明确隔离的教师/学生种子数据；先验证班级 A 看不到班级 B 的资料。
4. 只有完成目标 provider tool-call smoke、价格/预算确认和 MySQL V16 迁移验证后才演示 Agent 与费用。否则展示工作流模式及成本未知状态。
5. 录屏前检查浏览器网络面板、终端和页面均未暴露密钥或个人数据。

此文档是可复现脚本，不是已经录制的演示证据。暂无真实模型评分或生产容量数据。
