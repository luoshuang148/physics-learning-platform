# 简历项目描述（仅写有证据的版本）

## 推荐表述

**教学管理平台 AI 学习助手｜Java、Spring Boot、Vue、MySQL、RAG、Function Calling**

- 在已有教学平台中实现班级讲义检索增强辅导与复习计划助手；使用班级/版本受限的混合检索返回可追溯来源，历史引用读取时重新鉴权。
- 将本人错题、学情、知识检索和练习推荐封装为只读业务工具；采用确定性工作流并提供可选工具调用 Agent，后端限制工具参数、题目候选、交互轮数与执行时限。
- 实现复习计划预览、幂等保存、激活、作答版本失效校验和独立补练进度；运行台账记录阶段时长与可用 token 用量，缺失 usage/价格时成本显示未知。
- 验证：后端 unit 628 项、Python 评测合同 16 项通过（2026-10-23）；真实模型效果、人工物理复核、目标 provider 价格和生产容量尚未测定。

不要添加未经实测的准确率提升、成本节省比例、延迟数字或“Agent 效果优于工作流”。完成独立环境对照后再更新结果，并保留原始记录、样本分母、模型/语料版本与人工审核信息。
