# M1 三分钟演示脚本（知识库完成部署后）

演示只使用隔离环境中的合成班级、讲义、题目和学生账号；不展示真实学生数据。

| 时间 | 演示动作 | 讲解重点 |
|---|---|---|
| 0:00–0:25 | 教师进入“班级知识库”，选择演示班级 | 资料按班级授权；当前实现支持文本层 PDF、TXT、Markdown，索引状态由后端返回 |
| 0:25–0:55 | 上传一份牛顿定律讲义，等待状态变成“可用于辅导” | MySQL 保存权限与版本；Qdrant 是可重建索引；上传不等于立刻可检索 |
| 0:55–1:20 | 展示另一班级看不到该资料；撤回后列表状态变化 | 检索、历史来源和原文读取都重新验证当前权限/活动修订 |
| 1:20–2:20 | 学生提交一题演示错题，打开 AI 解惑，勾选“依据班级讲义辅导”并追问 | 展示 hybrid RAG、题目来自本人作答快照、SSE `sources` 不混入正文、引用卡片可展开 |
| 2:20–2:45 | 刷新页面并查看旧回答来源；再撤回讲义后重开历史 | 历史引用再次鉴权；资料不可用时显示占位，不能绕过撤回访问片段 |
| 2:45–3:00 | 展示实验状态页和评测运行命令 | 报告明确区分已测、待人工复核和未完成项；不把合成样例说成课堂效果 |

**当前演示准备状态：** 页面与 SSE/历史接口已实现，但尚未配置一次性 E2E 环境和完整演示数据。正式演示前，先完成教师复核、开发集评测并填入 `docs/ai-evaluation/m1-results.md`；不要展示为已发生的实验结果。
