## 内容初核发现

SDK 的 g0-07 回答：“因为摩擦力做负功导致动能减少”。这句话在未给定其他做功条件时过度推断：有摩擦的物体仍可能受到更大的驱动力而加速，动能变化由合外力总功决定。

所以 16 个回答通过来源编号格式校验，不等于 16 个物理回答全部正确。该例标为内容疑点/需改进，纳入下一阶段知识点与反例数据；不归因为框架效果差异，单次采样不足以支持此结论。

本报告是 AI 辅助事实与来源初核，尚无用户或教师人工评分。正式回答通过率、引用支持率仍为 pending，不填 100%。

## 选型

- 新增模块选择 LangChain4j 1.22.0 的核心模型适配；已有 SSE/视觉问答客户端保留。
- 原因：在现有 Spring Boot 3.3.8 依赖管理与 Java21 下，消息/用量/工具往返和取消合同均通过；可复用类型化工具/模型接口，减少手写协议。未证明它比 HTTP 更准确或更快。
- Embedding 使用 LangChain4j 1.22.0-beta32 本地中文量化 BGE 模型，512 维。云 embedding-3 的 429/1113 仍记录为不可用。
- SDK 取消测试只证明调用方行为，不能证明云厂商立即停止执行/计费。保留现有网络资源管理要求，正式接入继续验证。
- 本地模型仍需在部署机器测量内存与时延，不能直接认定在线试用机足够。
