# 8～10 分钟演示脚本（面试用）

前置：后端 `./mvnw spring-boot:run`（含 `ZHIPU_AI_API_KEY`），前端 `npm run dev`，
已导入演示题（`python3 scripts/seed_platform_rag.py`）。
账号：教师 `teacher / Teacher@2026`，学生 `stu01 / Student@2026`。

## 演示顺序

### 1. 平台搜题（1.5 min）
- 学生 → AI 助手 → **平台找题**
- 输入：「作用力与反作用力」
- 展示：MATCHED，来源卡（`Q:31:1:QUESTION:0`），点击查看原题
- 强调：来源 ID 结构 `Q:{qid}:{revision}:{part}:{ordinal}`，点击查看会**重新鉴权**

### 2. 无匹配 / 权限（1 min）
- 输入：「弦论的基本假设」→ 显示「平台暂无足够相关内容」
- 访问伪造来源 `Q:999:1:QUESTION:0` → 「来源不存在或已失效」，不泄露内容

### 3. 错题辅导（1.5 min）
- 从错题本点「问学习助手」（携带 recordId）
- 展示：区分「我的作答事实」与「题库最新解析」

### 4. Agent 工具调用（2 min）
- 复习计划 → 选作业「牛顿运动定律」→ 目标「作用力与反作用力」
- 执行模式 = AGENT（`AI_LEARNING_ASSISTANT_MODE=AGENT`）
- 展示 SSE `tool-step`：
  - `get_learning_summary` SUCCEEDED
  - `search_platform_questions` SUCCEEDED
  - `plan` 带 `reasonSourceIds`
- 强调：工具只能查本人数据，模型传不进 userId

### 5. 确认计划 → 补练（1.5 min）
- 保存草稿 → 激活
- 打开计划条目练习 `/student/practice?planId=&planItemId=`
- 提交作答 → 计入 planItemId 进度，**不混入原作业成绩**

### 6. 教师侧（1 min）
- 题库管理 → 开关「允许用于 AI 补练」
- 索引状态 `READY`，失败可「重试索引」

### 7. 评测数字（1 min）
打开 `docs/ai-evaluation/v2-results.md`：
| 指标 | dev | holdout |
|---|---|---|
| Hit@5 | 100%（27/27） | 100%（17/17） |
| 无结果处理 | 3/3 | 3/3 |
| 引用有效 | 100% | 100% |
| 延迟 p50/p95 | 57/91ms | 45/85ms |

说明：这是**冻结开发集后的留出实测**，不是调参后的数字。

## 可以讲的工程点

1. **为什么 SQL + RAG 分工**：作答/权限必须事务一致；找题允许模糊匹配。
2. **为什么按题目/段落分块**：同题多段不占满题目列表；长解析不静默截断。
3. **中文公式**：LaTeX 保持完整，分段避开公式块；关键词用 2/3 字 n-gram + 虚词过滤。
4. **混合召回失败案例**：「弦论」曾被「的基本」误召回 → 虚词 n-gram 丢弃规则。
5. **题库更新一致性**：revision 递增 + 租约 worker + 发布前再校验，旧任务晚完成不覆盖。
6. **工具边界**：白名单参数、重复调用识别、6 轮/8 次/60s 上限。
7. **成本与超时**：单模型 25s、`glm-4-flash` 免费档；费用未知时写 null，不估算。
8. **评测防过拟合**：开发/留出按 familyId 拆分，近重复不跨集；留出只跑一次。

## 面试追问准备

| 问题 | 答法 |
|---|---|
| Hit@5 会不会虚高？ | 分母只含「有相关题」的样例；无相关题单独统计；失败样例公开 |
| 如何防提示词注入？ | 注入文本只作数据；上下文进模型前先权限过滤；工具参数白名单 |
| 向量库挂了怎么办？ | UNAVAILABLE 显式报错，不假装无资料；可配置降级 lexical_only |
| 题目被删了旧来源还能看吗？ | 不能；每次读取重新鉴权 + revision 校验 |
| 为什么不用 BM25？ | 首版 MySQL 文本检索/分词适配器，如实标 lexical_only，不冒充全文检索 |
| 计划里的题一定是真的吗？ | 只能引用本次运行 registry 返回的 ID；保存/激活再校验 revision |
| 多少学生用过？ | 目前是演示环境，无真实用户规模；不填数 |
