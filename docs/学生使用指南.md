# 教学管理平台学生端使用指南

## 📘 学生版使用指南

### 一、登录与首页

1. 访问平台登录页，输入用户名与密码登录。
   - 登录只接受唯一用户名；真实姓名仅用于展示和教师检索，不能作为登录凭证。
2. 登录后进入学生首页，显示：
   - 当前教师发布的任务名称
   - 学习状态统计：累计答题数、正确率、待复习错题数
   - 最近错题预览
   - 下一步可选操作建议


### 二、学习流程

#### 1. 查看任务
- 点击「进入答题」，查看教师发布的题目任务
- 任务信息包括：任务名称、发布教师、发布时间和题目数量

#### 2. 自由探索 3D 实验（独立入口）
- 首页侧栏或「下一步」中点击「3D 实验」
- 可自由切换原子物理和宇宙航天实验，不绑定教师任务
- 支持全屏操作和实验内交互，不影响任务完成状态

#### 3. 完成练习答题
- 教师任务只包含题目，点击「开始答题」直接进入题目
- 操作步骤：
  1. 选择你认为正确的选项
  2. 点击「提交答案」
  3. 系统由服务端判分并立即保存首次作答；学生页面不依赖预先下发的正确答案
  4. 首次作答成功后，查看该题正确答案、解析，并可补充自己认为的错误原因
  5. （可选）如果有不清楚的，可以点击AI分析，获取深度分析报告，并且可以追问解惑
  6. 全部完成后显示完成提示，点击返回首页

#### 4. 生成学习报告

- 点击「学习报告」界面中的「生成报告」，查看 AI 生成的个性化学习报告
- 报告基于你的答题记录和错误分析生成
- 包含知识点掌握情况、薄弱环节、改进建议等

### 三、AI 悬浮球

**全程可用的 AI 学习助手**，界面右下角有一个悬浮按钮：

#### 基本功能
- 点击按钮打开 AI 对话面板
- 支持文字输入提问物理问题
- HTTP环境下，语音输入暂不支持
- 支持上传图片提问（点击图片上传或 Ctrl+V 粘贴，可使用Win+shift+S快捷截图后粘贴），目前仅限一张图片
- 点击「清空会话」，会一键清空本轮悬浮球AI助手的聊天记录

#### 使用场景
- 学习过程中遇到不懂的概念
- 实验现象有疑问
- 题目理解困难

#### 操作说明
- 按 `Ctrl+Enter` 快速发送
- 发送后可查看 AI 思考过程
- 支持中断 AI 生成

### 四、错题本

- 进入「错题本」查看历史错题记录
- 显示题目内容、你的错误答案、正确答案
- 支持查看错题详情和解析
- 此处同样可以使用AI错题分析功能

### 五、物理实验操作指南

本平台提供8个物理虚拟实验，可在3D模拟环境中进行自主探究学习。

#### 5.1 卢瑟福α粒子散射实验

**实验简介**：模拟α粒子轰击金原子核的散射现象，验证原子的核式结构模型。

**操作步骤**：

1. **发射粒子**：点击「**开始/停止：连续发射**」按钮，观察α粒子在金原子核附近的偏转

2. **旋转观察窗**：拖动「**观察窗角度**」滑块（0°-360°），查看不同方向的散射粒子数量，可切换实时/累积模式

3. **一键采集**：点击「**一键采集**」按钮，自动统计并绘制散射分布图

4. **切换视角**：点击「**切换至【微观/宏观】视角**」可在不同视角间切换观察

5. **重置实验**：点击「**重置全部**」清除所有数据，重新开始

#### 5.2 玻尔原子理论

**实验简介**：可视化展示玻尔原子模型中的电子轨道和能级跃迁。

**操作步骤**：
1. 选择光子/电子模式
2. 输入相应的能量参数
3. 点击按钮发射

#### 5.3 电子云模型

**实验简介**：展示原子核外电子的概率分布，理解电子云的形成。

**操作步骤**：
1. 选择不同的轨道类型，可拖动滑块观察剖面
2. 使用单电子追踪功能，理解如何通过统计累积得到电子概率性的分布

#### 5.4 光电效应实验

**实验简介**：模拟光电效应实验，验证爱因斯坦光电方程。

**操作步骤**：

1. **选择金属材料**：从下拉菜单选择阴极材料（铯、钠、锌、铂）

2. **调节入射光频率**：拖动「**入射光特征**」滑块，观察是否发生光电效应

3. **调节光强**：拖动「**光照强度**」滑块，观察饱和电流变化

4. **调节外加电压**：拖动「**外加偏置电压**」滑块，观察：
   - 正向电压：加速电子，电流增大
   - 反向电压：减速电子，电流减小
   - 达到截止电压时：电流为零

5. **观察I-U曲线**：右侧实时绘制光电流-电压曲线

6. **记录截止电压**：观察不同频率对应的截止电压值

#### 5.5 开普勒三大定律探究

**实验简介**：通过发射探测器验证开普勒三大定律。

**操作步骤**：

1. **调节轨道参数**：
   - 拖动「**轨道半长轴 a**」滑块设定轨道大小
   - 拖动「**轨道偏心率 e**」滑块设定轨道形状
   - 观察椭圆轨道特征

2. **发射探测器**：点击「**🚀 发射探测器 (记录数据)**」，右侧自动记录数据

3. **验证面积定律**：点击「**📐 演示面积定律**」，观察相等时间内扫过的面积

4. **多发几次**：多次发射不同参数的探测器，对比数据

5. **查看实验结果**：观察右侧表格中的数据是否符合假设

#### 5.6 三大宇宙速度

**实验简介**：模拟飞船在不同初速度下的轨道运动，直观理解三大宇宙速度的物理意义。

**操作步骤**：

1. **手动调节速度**：拖动「**发射初速度**」滑块

2. **发射飞船**：点击「**发射**」按钮，观察飞船轨道

3. **快速演示**：使用预设按钮切换不同速度区间：
   - 「**第一宇宙速度以下**」：飞船坠落
   - 「**第一~第二宇宙速度**」：绕地轨道
   - 「**第二~第三宇宙速度**」：逃逸地球，进入绕日轨道
   - 「**第三宇宙速度以上**」：双曲线逃逸

4. **调节时间流速**：拖动「**演示速率**」滑块，加快或减慢演示

5. **重置**：点击「**重置**」清除当前轨道

#### 5.7 霍曼转移轨道

**实验简介**：模拟卫星变轨的两次点火操作。

**操作步骤**：

1. **设定目标**：拖动「**目标轨道半径**」滑块选择目标轨道高度

2. **第一次点火**：点击「**第 1 次点火 (A点切入)**」，飞船进入椭圆转移轨道

3. **等待至B点**：观察飞船沿椭圆轨道运行至转移轨道与目标轨道交汇点

4. **第二次点火**：当「**第 2 次点火 (B点圆化)**」按钮可用时点击，完成轨道圆化

5. **切换视角**：点击「**追踪视角**」跟随飞船视角观察

6. **重置**：点击「**重置**」重新开始


#### 5.8 相对论视觉模拟器

**实验简介**：模拟接近光速运动时观察到的光行差与多普勒效应现象。

**操作步骤**：

1. **手动调节速度**：拖动「**速度比率 β = v/c**」滑块，从0逐渐增加至接近1

2. **自动加速体验**：
   - 点击「**🚀 缓变加速**」：8秒内匀速加速至0.95c
   - 点击「**⚡ 急变加速**」：2秒内快速加速至0.95c

3. **旋转视角**：按住鼠标左键拖动，可自由旋转观察方向

4. **观察效果**：
   - 前方星光蓝移变亮
   - 后方星光红移变暗
   - 前方视野范围逐渐收窄

## 作业进度与复盘

每题提交成功后即保存。开放期间，0题为未开始、部分为进行中、全部保存为已完成；截止后，0题为未交、部分为未完成，未到开放时间为未开放。完成与答对题数无关。“继续作答”定位下一道未答题，未保存的答案优先恢复重试。

作业结果中的 AI 复盘会读取服务器保存的同版本内容；新增作答或补练后需要重新生成。AI 已配置不等于当前模型可调用，页面会说明最近调用失败或尚未验证的情况。新注册学生只加入尚未截止的作业。
