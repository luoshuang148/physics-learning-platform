## 数据库配置

### 方式一：Docker 启动 MySQL（推荐）

```powershell
# 启动 MySQL 容器
docker run -d --name zhixuewuli-mysql `
  -e MYSQL_ROOT_PASSWORD=rootpassword `
  -e MYSQL_DATABASE=zhixuewuli `
  -p 3306:3306 `
  mysql:8.0

# 检查容器状态
docker ps
```

### 方式二：本地安装 MySQL

1. 安装 MySQL 8.0+
2. 创建数据库：
```sql
CREATE DATABASE zhixuewuli CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```
3. 修改配置文件 `src/main/resources/application-dev.yml` 中的数据库连接信息：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/zhixuewuli?useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: root
    password: your_password
```

## 后端启动

### 后端启动说明

- 项目默认使用 `dev` 环境启动（见 `scripts/start-backend.bat`）。
- 视频上传文件默认保存到相对目录 `./data/videos`。
- 这里的相对目录是**相对于后端启动时的工作目录**计算的；按项目默认脚本启动时，实际目录通常为项目根目录下的 `data/videos`。
- 首次上传视频时，后端会自动创建该目录，无需手动新建。

### 方式一：Maven 启动（开发环境推荐）

```powershell
# 进入项目根目录
cd <your-project-path>  # 例如: cd c:\Users\35283\Desktop\zxwl_vlab

# 编译项目（首次运行或代码变更后）
mvn clean package -DskipTests

# 启动后端服务（推荐带上 dev profile）
java -jar target\zhixuewuli-backend-1.0.0.jar --spring.profiles.active=dev
```

### 方式二：使用启动脚本

```powershell
# 进入 scripts 目录
cd scripts

# 运行后端启动脚本
.\start-backend.bat
```

### 方式三：Docker Compose 启动

```powershell
# 启动所有服务（MySQL + 后端）
docker-compose up -d
```

### 后端服务信息

启动成功后，可访问以下地址：

| 服务 | 地址 |
|------|------|
| API 基础路径 | http://localhost:8080/api/v1 |
| API 文档 | http://localhost:8080/api/v1/swagger-ui.html |
| 健康检查 | http://localhost:8080/api/v1/actuator/health |

## 一键启动

### 使用 start-all.bat 脚本

项目根目录提供了 `start-all.bat` 一键启动脚本，可同时启动前后端服务：

```powershell
# 在项目根目录运行
.\start-all.bat
```

### 手动分别启动

如果需要分别启动前后端，可以按以下顺序：

1. **启动数据库**（Docker 方式）
```powershell
docker start zhixuewuli-mysql
```

2. **启动后端**
```powershell
java -jar target\zhixuewuli-backend-1.0.0.jar
```

3. **启动前端**
```powershell
cd frontend
npm run dev
```

## 终止项目

### 方式一：手动终止各服务

#### 1. 终止前端服务

在运行前端的终端窗口中，按 `Ctrl + C` 终止 Vite 开发服务器。

或者通过命令行终止：
```powershell
# 查找占用 5173 端口的进程
netstat -ano | findstr :5173

# 终止进程（替换 PID 为实际进程 ID）
taskkill /PID <PID> /F
```

#### 2. 终止后端服务

在运行后端的终端窗口中，按 `Ctrl + C` 终止 Spring Boot 应用。

或者通过命令行终止：
```powershell
# 查找占用 8080 端口的进程
netstat -ano | findstr :8080

# 终止进程（替换 PID 为实际进程 ID）
taskkill /PID <PID> /F
```

#### 3. 停止数据库容器

```powershell
# 停止 MySQL 容器
docker stop zhixuewuli-mysql

# 如需删除容器（数据会保留在 Docker Volume 中）
docker rm zhixuewuli-mysql
```

### 方式二：Docker Compose 终止

如果使用 Docker Compose 启动的服务，可以一次性终止所有服务：

```powershell
# 停止所有服务
docker-compose down

# 停止服务并删除数据卷（会清除数据库数据）
docker-compose down -v
```

### 方式三：终止所有相关进程

```powershell
# 终止所有 Java 进程（谨慎使用，会终止所有 Java 应用）
taskkill /IM java.exe /F

# 终止所有 Node.js 进程（谨慎使用，会终止所有 Node 应用）
taskkill /IM node.exe /F
```

### 服务终止检查

终止后，可以验证服务是否已完全停止：

```powershell
# 检查端口是否已释放
netstat -ano | findstr :8080
netstat -ano | findstr :5173
netstat -ano | findstr :3306

# 检查 Docker 容器状态
docker ps
```

> **提示**：如果端口查询无输出，说明服务已成功终止。

## 常见问题

### 1. 端口被占用

**问题**：启动时报错端口 8080 或 5173 被占用

**解决方案**：
```powershell
# 查看端口占用
netstat -ano | findstr :8080
netstat -ano | findstr :5173

# 终止占用进程（替换 PID 为实际进程 ID）
taskkill /PID <PID> /F
```

### 2. 数据库连接失败

**问题**：后端启动报错无法连接数据库

**解决方案**：
1. 确认 MySQL 服务已启动
2. 检查数据库连接配置是否正确
3. 确认数据库用户名密码正确

```powershell
# 检查 MySQL 容器状态
docker ps | findstr zhixuewuli-mysql

# 如果容器未运行，启动它
docker start zhixuewuli-mysql
```

### 3. 前端依赖安装失败

**问题**：npm install 报错

**解决方案**：
```powershell
# 清除 npm 缓存
npm cache clean --force

# 删除 node_modules 目录
Remove-Item -Recurse -Force node_modules

# 重新安装依赖
npm install
```

### 4. Maven 构建失败

**问题**：mvn package 报错

**解决方案**：
```powershell
# 清除 Maven 缓存
mvn clean

# 强制更新依赖
mvn clean install -U
```

### 6. 视频上传后无法打开

**问题**：视频上传成功，但点击“打开链接”返回 404 或空白页。

**排查与说明**：
1. 确认后端已重启，使最新配置生效。
2. 当前项目默认将视频保存到相对目录 `./data/videos`。
3. 如果使用项目自带脚本启动后端，该目录通常对应项目根目录下的 `data/videos`。
4. 可检查目录中是否已生成上传后的 `.mp4` 文件。
5. 视频静态访问地址格式为 `http://localhost:8080/videos/文件名.mp4`。

**建议操作**：
```powershell
# 在项目根目录查看上传目录
Get-ChildItem .\data\videos
```

如果目录中没有文件，请重新上传一个视频后再测试。

### 7. AI 功能无法使用

**问题**：AI 助手功能返回认证失败

**解决方案**：
1. 检查 `src/main/resources/application-dev.yml` 中的 AI API 密钥配置
2. 确认智谱 AI 和阿里云百炼 API 密钥有效
3. 如无密钥，可在以下地址申请：
   - 智谱 AI：https://open.bigmodel.cn/
   - 阿里云百炼：https://bailian.console.aliyun.com/
