# 本地启动

配置入口是仓库根目录 `.env.dev.example`。复制为 `.env` 后修改；`.env` 已被 Git 忽略，Spring Boot 会读取它。需要 JDK 21、Node.js 22 和 MySQL 8.0+。

1. 确认 `java -version` 是 21；多 JDK 环境设置 `JAVA_HOME`。
2. 配置 `.env` 中 `DB_HOST/DB_PORT/DB_NAME/DB_USER/DB_PASSWORD` 及随机的 `APP_JWT_SECRET`。初始化脚本默认建库名为 `zhixuewuli`，自定义库名需相应调整 SQL。
3. 创建空数据库即可；应用启动时由 Flyway 自动建表：`mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS zhixuewuli CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"`。
4. 如需首次教师，设置 `BOOTSTRAP_TEACHER_ENABLED=true`、3–50 位字母数字下划线用户名及至少 12 字符的自选密码。初始化会创建 BCrypt 密码的教师；已有同名教师不会改密码，已有同名学生会报错。
5. 在项目根目录运行 `./mvnw spring-boot:run`。默认 profile 为 `dev`，也可显式 `-Dspring-boot.run.profiles=dev`。启动后关闭教师初始化并从 `.env` 删除密码。
6. 进入 `frontend`，运行 `npm ci`、`npm run dev`，访问 `http://localhost:5173`。Vite 默认代理 `/api/v1` 到本机 8080；后端使用其他端口时，例如 18080，用 `VITE_DEV_PROXY_TARGET=http://127.0.0.1:18080 npm run dev` 启动前端。
7. 批量学生报告依赖 RabbitMQ：Docker 环境执行 `docker compose up -d rabbitmq` 后按 `.env` 中的 `RABBITMQ_*` 连接（默认 `localhost:5672`、guest/guest）。暂时不用该功能时设 `REPORT_BATCH_ENABLED=false`，此时消费、发件箱投递与租约恢复都会暂停，重新开启后继续处理存量批次。

本地默认 `AI_ENABLED=false`，允许不填模型密钥。关闭时传统 AI 请求会返回不可用错误，不连接模型服务器。知识库默认关闭；启用 RAG 需设置 `APP_KNOWLEDGE_ENABLED=true` 并启动 Qdrant。学习计划默认使用确定性的 `WORKFLOW` 模式；动态 Agent 默认关闭，需显式设置 `AI_AGENT_TOOL_CALLING_ENABLED=true` 并配置 `AI_AGENT_BASE_URL`、`AI_AGENT_API_KEY`、`AI_AGENT_MODEL`。使用独立测试学生和题库验证，别把真实学生信息发送给外部模型。

学生可从“AI 学习助手”页按作业生成复习计划，查看工具步骤和证据摘要，确认后保存/激活并进入补练。AI 生成结果是待检查的计划预览；运行详情为 `/api/v1/ai/student/learning-plan/runs/{runId}`，仅本人可读取。用量缺失或价格未配置时成本显示未知，不代表免费。

开发后端地址是 `http://localhost:8080/api/v1`；前端开发地址是 `http://localhost:5173`。视频默认写入 `./data/videos`。普通用户通过注册页面创建学生账号，额外教师可由运营初始化，或由已授权教师通过受保护的用户管理 API 授予角色；当前学生名册页面只管理学生信息。

常见问题：

- `release version 21 not supported`：Maven 使用了旧 JDK，检查 `./mvnw -v` 的 Java 版本。
- `Schema-validation` 或 Flyway 校验失败：旧库未完成 V7 升级，或 Flyway 历史与库结构不一致；先备份并按部署指南处理，不要用旧版删库脚本覆盖现有数据。
- 数据库连接失败：检查本机 MySQL、端口、账号及 `.env`；本地模板的主机应为 `127.0.0.1`，容器使用服务名 `mysql`。
- 默认教师登录失败：不提供默认口令，按第 4 步指定自己的首次教师账号。
- 批量报告一直停在排队中：检查 RabbitMQ 是否启动、`REPORT_BATCH_ENABLED` 是否为 true；重启后在“作业详情”页刷新批次，发件箱与租约恢复会继续未完成的投递。
- AI 被关闭：确认 `AI_ENABLED`；无需为普通功能打开 AI。

回归：根目录 `./mvnw -B test`；前端 `npm test && npm run build`。默认后端套件使用 H2，真实 MySQL 验证见 README。
