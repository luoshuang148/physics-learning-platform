# 主题颜色系统说明

本文档说明项目中 `Shared/color.css` 的颜色变量、主题方案与切换方式。

## 1. 颜色角色定义

系统统一使用四种角色色：

- `--color-primary`：主要色（大面积背景/主视觉）
- `--color-secondary`：次要色（模块标题/辅助信息）
- `--color-content`：内容色（正文文字）
- `--color-accent`：重点色（强调数据/关键按钮/高亮）

其中：

- `--color-content` 固定为白色：`#ffffff`

## 3. CSS 引用方式

在页面中先引入共享样式：

```html
<link rel="stylesheet" href="../Shared/color.css">
<link rel="stylesheet" href="../Shared/theme.css">
```

在样式中直接使用变量：

```css
.title {
  color: var(--color-secondary);
}

.panel {
  background: var(--theme-panel-bg);
  border: 1px solid var(--theme-panel-border);
}

strong {
  color: var(--theme-accent);
}
```

---

## 4. 主题切换方式

通过切换 `html`（或 `body`）上的 `data-theme`：

```js
document.documentElement.setAttribute('data-theme', 'guzhi-liujin');
```

！！ 整体切换需要将每个html的data-theme值都修改才可以整体切换

可用主题值：

- `guzhi-liujin`
- `mailang-qingye`
- `zhizong-senlv`
- `ziyuan-jinhui`
- `qingkong-shenhai`

建议保存用户选择：

```js
function setTheme(theme) {
  document.documentElement.setAttribute('data-theme', theme);
  localStorage.setItem('theme', theme);
}

setTheme(localStorage.getItem('theme') || 'guzhi-liujin');
```

---

## 5. 规范建议

- 新页面禁止硬编码颜色（如 `#00e5ff`），统一使用语义变量。
- 面板统一使用：
  - 背景：`var(--theme-panel-bg)`
  - 边框：`var(--theme-panel-border)`
- 强调文本（如统计值、`strong`）优先使用：`var(--theme-accent)`
- 按钮统一使用：
  - 背景：`var(--theme-button-bg)`
  - 边框：`var(--theme-button-border)`
